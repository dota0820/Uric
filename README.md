# 尿酸管家 Uric Care

为 **50–60 岁马来西亚高尿酸 / 痛风长辈**设计的简单网页 App，支持华语和英文。
手机打开网址就能用，也可以"加到主屏幕"，像 App 一样打开。

## 功能

| 首页大按钮 | 做什么 |
|---|---|
| 📷 拍食物 | 拍照、讲话或打字 → 🟢 可以吃 / 🟡 少量 / 🔴 避免，再给一个"换个点法"的建议 |
| 📄 拍验血报告 | AI 读出数字 → 系统用医学标准判断 → 用大白话解读，并和上次的报告比较 |
| 💬 问我的管家 | 专属 AI，记得你的尿酸记录、用药和病史；可以按 🎤 用讲的 |
| 📈 尿酸趋势 | 每次报告自动记录并画图；超过 90 天没验会提醒复查 |
| 💧 喝水 | 一天 8 杯，点一下记一杯 |
| 📚 知识 / 🚶 运动 | 正确知识卡片，每张都有 🔊 朗读 |

为长辈做的设计：字体大（右上角 **A+** 可以再放大）、按钮大、可以讲话输入、可以朗读回答、底部只有 4 个页签。

## 准确性怎么保证

AI 只负责"看"，判断由程序来做：

- **食物**：AI 只负责认出照片里的食物，再对照 `lib/purine-db.js`（约 90 种食物，包括肉骨茶、椰浆饭、叻沙、炒粿条等本地菜）。红绿灯由数据库决定，AI 不能自己编嘌呤数字。
- **验血报告**：AI 只负责把数字和单位原样抄出来。单位换算（mg/dL → µmol/L）和"正常 / 偏高"的判断都写死在 `lib/labs.js`，并且有测试。
- **安全**：AI 不能叫用户停药或换药；肾功能严重下降、尿酸 ≥ 600 等危险信号会用红色框提醒看医生。

## 推荐模型（通过 OpenRouter）

| 用途 | 模型 | 原因 |
|---|---|---|
| 验血报告 | `google/gemini-4-argon` | Google 目前的旗舰推理模型，读小字表格最准；用量少，贵一点没关系 |
| 食物、聊天 | `google/gemini-3.8-flash` | 快、便宜，看图能力足够 |

想换模型，在 `.env` 里改 `MODEL_SMART` / `MODEL_FAST` 就可以。

## 运行

```bash
npm install
cp .env.example .env      # 填入 OPENROUTER_API_KEY
npm start                 # http://localhost:3000
```

没有填 key 时会以**示范模式**运行，回答是固定的，方便先看界面。

```bash
npm test
```

## 隐私

用户的资料、报告和聊天记录**只存在自己手机的浏览器里**（localStorage），服务器不保存。
照片只会发送给 AI 分析，分析完就丢掉。这样比较符合马来西亚 PDPA 的要求。
缺点是换手机或清除浏览器资料后，记录就会消失（下一阶段可以加登录和云端备份）。

## 文件结构

```
server.js            后端：/api/food、/api/report、/api/chat
lib/purine-db.js     嘌呤食物数据库（红绿灯）
lib/labs.js          验血指标：单位换算 + 判断 + 危险信号
lib/prompts.js       AI 指令（包括安全规则）
lib/llm.js           OpenRouter 调用
lib/demo.js          示范模式的固定回答
public/              前端（纯 HTML/JS，不需要编译）
```
